Comment utiliser le mode Swipe

📱 Sur mobile

  • Glisser vers la gauche : Passer le jeu (← PASSER)
  • Glisser vers la droite : Lancer le jeu (→ LANCER)

💻 Sur ordinateur

  • Glisser la carte avec la souris vers la gauche ou la droite
  • Flèche gauche ← : Passer le jeu
  • Flèche droite → : Lancer le jeu

🎮 Manette

  • Utilisez le stick analogique ou la croix directionnelle pour naviguer.
  • Gauche : Passer le jeu
  • Droite : Lancer le jeu

💡 Astuces

  • Les jeux passés ne réapparaîtront pas jusqu'à ce que tous les jeux aient été vus
  • Quand tous les jeux ont été passés, le paquet est automatiquement rebrassé
  • Un cercle coloré apparaît du côté choisi pour indiquer votre action
